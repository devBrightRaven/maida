# Maida ユーザーマニュアル

**バージョン：v0.5.0**

---

## これは何ですか？

Maida は、あなたと Steam ライブラリのあいだにある静かな場所です。

何を遊ぶか、遊ぶかどうかも、あなたが決めます。

Maida には3つのモードがあり、左側のサイドナビゲーションに並んでいます：
- **間合（Maai）**：ゲームを1ページにまとめ、3つの小さなゾーンに分けて並べます。Maida を開くと、まずここに来ます。
- **臨（Rin）**：ゲームが1つずつ現れます。遊ぶなら「やる」、違うなら「これじゃない」。
- **構（Kamae）**：「型（Kata）」を整えます。型は、臨でゲームが出てくる小さなグループです。

---

## インストール前に

### Windows：SmartScreen 警告

Maida を初めて起動すると、Windows に **「Windows によって PC が保護されました」** と表示されます。Maida がコード署名されていないためです。証明書は年間 300 ドル以上かかり、個人が作る無料ソフトには見合いません。

続行するには：**詳細情報** → **実行** をクリックします。ダウンロード数が増えれば警告は出なくなります（SmartScreen の評価は自動的に積み上がるので、操作は不要です）。

信頼する前に確認したい場合：
- ソースコード公開：[github.com/devBrightRaven/maida](https://github.com/devBrightRaven/maida)（MIT ライセンス、すべての行を読めます）
- 匿名利用データの送信は、設定でいつでもオフにできます
- 開発者の連絡先：bertram@brightraven.world

### ROG Ally：ゲームパッドモード

ROG Ally でボタンが Maida に効かない場合は、**Armoury Crate** を **ゲームパッドモード** にするか、Maida をゲームプロファイルに追加してください。ボタンがキーボード／マウスの割り当てではなく、ゲームパッドの信号として送られるようになります。

## 初回セットアップ

1. Maida を開く
2. **言語を選ぶ**。4つの選択肢（English、日本語、简体中文、繁體中文）はそれぞれの文字で表示され、システムの言語があらかじめ選ばれています。後から設定で変更できます。
3. 「**ライブラリをスキャン**」を押す。ゲームは起動せず、データもデバイスの外に出ません。
4. スキャンが終わるまで待つ
5. 完了。インストール済みのゲームがランダムに3つ入った「Demo Kata」ができるので、臨ですぐにゲームが現れます。

スキャンのときに Steam を起動しておく必要はありません。Maida はディスクから直接ライブラリを読み取ります。

## モードの移動

左側のサイドナビゲーションは、ページをスクロールしても動きません。並んでいるのは：

- 3つのモード：**Maai 間合い**（円）、**Rin 臨**（三角）、**Kamae 構**（四角）
- **選択の履歴**
- **設定**

モードはサイドナビゲーションから、またはゲームパッドの **LB / RB** で切り替えます（間合 → 臨 → 構、そして最初へ）。キーボードでは **Ctrl+Tab** で臨と構を行き来し、**F9** で間合、**F8** で臨に移ります。

どのモードからでも、**F10** またはゲームパッドの **Menu** ボタンで設定が開きます。設定を閉じると、元のモードに戻ります。

サイドナビゲーションをコンパクトにしたい場合は、設定 → **モードの切り替え方** で「**C · 前後に切り替え**」を選びます。前後のモードと現在の位置（例：1 / 3）だけが表示されます。

## 間合（Maai）：あなたのゲーム

### 3つのゾーン

間合では、ゲームを3つのゾーンと全体の一覧に分けて表示します：

- **最近開いた**：Steam にプレイ記録があるゲーム。最近遊んだものから順に（最大5つ）。
- **残してある**：想いを留めたゲーム（下記参照）。新しいものから順に。
- **インストールしたばかり**：インストール済みで、Steam にプレイ記録がないゲーム。新しく加わったものから順に（最大5つ）。
- **インストール済みすべて**：インストール済みのすべてのゲーム。最初は閉じていて、押すと展開します。

カードには Steam が把握している情報だけが表示されます。プレイ記録がなければ、カードにそう書かれます。何を遊んだかを Maida が推測することはありません。

### ゲームを開く

カードを短く押す（クリック、Enter、または A）と、Steam 経由でゲームが起動します。そのあと Maida は起動後の画面に切り替わります（「**ゲームを起動したあと**」を参照）。

マウスの場合、ポインターをカードの上に1秒ほど置くと、起動せずにフォーカスだけが移ります。

カードにしばらくフォーカスがあると（既定では3秒）、そのゲームのトレーラーやスクリーンショットが背景に流れます。待ち時間と音声は、設定 → アクセシビリティ で変更できます。

### 想いを留める

今は遊ばなくても、忘れたくないゲームがあります。

**カードを3秒長押し**します（マウス、Enter、A のどれでも）。「何を覚えておきたいですか？」という入力欄が開くので、ひとこと書いて **保存**（または Enter）を押します。Escape で取り消せます。

ゲームはメモと一緒に「**残してある**」に並びます。残してあるカードには、ボタンがいくつか加わります：

- **この想いを手放す**：「残してある」から外します。元のメモは選択の履歴に残ります。
- **留める／休ませる／手放す**：今このゲームをどう扱うかの印です。「休ませる」か「手放す」にしたゲームは、「最近開いた」と「インストールしたばかり」に出なくなります。
- **選択の履歴**：このゲームの記録だけを表示します。

## 臨（Rin）：1つずつ

表示されるもの：
- ゲームタイトル（アートがあれば一緒に）
- 短いメッセージ（「処方箋」と呼びます）
- 2つのボタン：**「やる」** と **「これじゃない」**

### やる

今このゲームを遊んでもいいなら、**「やる」を押します**。

すると：
- ゲームがすぐに起動します
- その選択が記録されます（重み +1）
- 起動後の画面に切り替わります

### これじゃない

今はこのゲームを遊びたくないなら、**「これじゃない」を押します**。

すると：
- 別のゲームが現れます
- このゲームは今回のセッション中には出てきません
- 何度も見送ったゲームは、出てくる頻度が大きく下がります

### 空の型

アクティブな型にゲームがまだない場合は、臨にそう表示され、「やる」と「これじゃない」は使えません。構でゲームを追加するか、別の型に切り替えてください。

---

## 構（Kamae）：グループの整理

サイドナビゲーションの「Kamae 構」から、または臨で **Ctrl+Tab** / **RB** を押すと構に入ります。

構でできること：
- 型をカードで確認する（各カードにゲームの小さなカプセル画像が並びます）
- インストール済みのゲームを検索して、アクティブな型に追加する
- 型の作成、名前の変更、削除

### 型（Kata）

型は名前の付いたゲームのグループです。気分やテーマごとに作れます。

- 型は最大2つ（各型に最大15ゲーム）
- 臨では、アクティブな型のゲームだけが出てきます
- 「インストール済み全ゲーム」を選ぶと、インストール済みのすべてのゲームが臨に出てくるようになります
- F2 キーまたはコントローラーの Y ボタンで型の名前を変更できます

#### 操作方法

| 操作 | 方法 |
|------|------|
| 型を作成 | 「新しい型」ボタンを押す |
| 型を削除 | 「×」を押すと「?」に変わるので、もう一度押して削除 |
| 名前変更 | F2 キーまたはコントローラーの Y ボタン |
| ゲーム追加 | 型のカードで「+」を押してゲームにチェックを入れる、または検索欄で名前から探す |
| ゲーム削除 | 「外す」を押すとボタンが「削除しますか？」に変わります。もう一度押して確定、Esc / B で取り消し。または Enter / A を2.5秒長押し。 |

## 本当にこれだけです

Maida を使うために、ほかに知っておくことはありません。ここから先はすべてオプションです。

## オプション：アンカー

今決めておいて、遊ぶのは後にしたいとき。

**臨で「やる」ボタンを3秒長押しします。**

すると：
- ゲームが画面に「アンカー」され、「**アンカー**」の印が付きます
- 「やる」が **「プレイ」** に変わります
- 「これじゃない」が **「解除」** に変わります
- 次に臨を開いても、このゲームはそのまま残っています

**気が変わったら** 「解除」を押してください。

---

## オプション：元に戻す

臨で押し間違えましたか？

画面下部の「**元に戻す（一回限り）**」ボタンを押します。

1ステップ戻ります。使えるのは決定ごとに1回だけです。別の型に切り替えると、元に戻せなくなります。

注意：元に戻すとゲームは画面に戻りますが、-2 の重みのペナルティは戻りません。スコアは毎日の減衰で、1週間ほどで自然に回復します。

---

## オプション：選択の履歴

サイドナビゲーションの「**選択の履歴**」を押すと、残したメモと操作の記録が新しい順に表示されます。留めた・編集した・手放した想い、設定した状態、起動したゲーム、そして臨での「やる」「これじゃない」「プレイ」「元に戻す」「アンカー」の操作です。

表示されるのは、実際にある記録だけです。過去の選択を補ったり、理由を推測したりはしません。

「**戻る**」（または Escape / B）で閉じます。

---

## ガイドツアー

ガイドツアーは臨と構の使い方を案内します。臨を初めて開くと、右上の **?** ボタンが目立つように表示されます。押す（または **F1** を押す）とツアーが始まり、次の内容を案内します：

- ゲームタイトルと処方箋の意味
- 「やる」と「これじゃない」の使い方
- 構への切り替え方
- 構での型とゲームの管理
- 臨への戻り方

ツアーはいつでも見直せます。臨か構で ? または F1 を押すか、設定 → 操作ガイド → **もう一度見る** から開けます。

## ゲームを起動したあと

### 起動後に何が起こるか

ゲームを起動すると（間合のカード、「やる」、「プレイ」のどれからでも）、Maida は一歩下がります。画面には「**いまは、ゲームの中**」と短いカウントダウンが表示されます。

離れているあいだは：
- 新しい選択肢は出てきません
- タイトルの下に短いメッセージが表示されます。左右キーで別のメッセージに切り替えられます

### 戻ってきたら

遊び終わったら Maida に戻り、「**Maida に戻る**」を押します。

このボタンは休憩時間が過ぎてから押せるようになります（既定は15秒。設定 → アクセシビリティ → 試した後の休憩時間 で5〜30秒に変更できます）。2度押しでうっかりこの画面を飛ばさないためです。

---

## 臨にどのゲームが現れるか

決めるのは、あなた自身の選択です：
- 「やる」を押したゲーム → より頻繁に現れる
- 「これじゃない」を押したゲーム → 現れにくくなる
- すべての重みは毎日減衰し、中立に近づいていく

Maida があなたのゲームに順位を付けることはありません。重みは、あなた自身の選択がどちらに傾いているかを映しているだけです。

間合では重みを一切使いません。各ゾーンの並び順は、Steam のプレイ記録、インストールした時期、想いを留めた時期という事実だけで決まります。

## 設定

サイドナビゲーションの「設定」、または F10 / Menu で開きます。「**閉じる**」（または Escape / B を2回）で閉じます。一部のセクションは、タイトルを押すと展開します。

- **操作ガイド**：「もう一度見る」でツアーを再生します。
- **モードの切り替え方**：「**サイドナビゲーション**」（3つのモードを並べて表示）か「**C · 前後に切り替え**」（コンパクト表示）。
- **言語**：English、日本語、简体中文、繁體中文。言語を選んだあと、もう一度押して適用します。
- **アクセシビリティ**：
  - **振動**：オフ／低／中／高。変更はすぐに反映されます（ゲームパッドのみ）。
  - **試した後の休憩時間**：ゲームを起動してから Maida に戻れるようになるまでの時間。5〜30秒（既定15秒）。
  - **プレビューまでの時間**：間合のカードにフォーカスが移ってから、プレビューが流れ始めるまでの時間。1・3・6秒（既定3秒）。
  - **プレビュー音声**：オン／オフ（既定はオン）。
  - **カードの不透明度**：間合のカードが背景からどれだけ透けるか。40%〜100%（既定70%）。
  - **アクセシビリティ声明を表示**：アクセシビリティ声明のページを開きます。
- **操作説明**：臨、構、共通のキーボードとゲームパッドの操作一覧。
- **外観**：ライト／ダークモードの切り替え。
- **IGDB（ゲーム時間データ）**：任意。Twitch Developer の認証情報を入力すると、推定プレイ時間を表示できます。
- **匿名利用データ**：起動ごとに小さな匿名シグナル（ランダム ID・インストール日数・バージョン）を送ります。いつでもオフにできます。

設定値はすべて、次回の起動にも引き継がれます。

## よくある質問

**Q：臨で同じゲームが何度も出てくるのはなぜ？**
以前、そのゲームで「やる」を何度か押したからです。Maida はプレイ時間を追跡せず、選択だけを記録します。もう十分なら「これじゃない」を押してください。

**Q：特定のゲームを検索できますか？**
構では検索して型に追加できます。間合では「インストール済みすべて」を開けば一覧で見られます。臨ではできません。臨は1つのゲームと向き合う場所です。

**Q：プレイ時間を追跡しますか？**
いいえ。間合に表示されるのは Steam 自身のプレイ記録（遊んだことがあるか、最後にいつ遊んだか）です。Maida がプレイ時間を計ることはありません。

**Q：データはどこかにアップロードされますか？**
いいえ。ゲーム、メモ、履歴はすべてデバイス上に保存されます。送信されるのは起動時の匿名シグナルだけで、これもオフにできます。

## トラブルシューティング

### 「Steam が検出されません」

Maida がディスク上で Steam のインストールを見つけられませんでした。`steamapps/libraryfolders.vdf` ファイルを以下の標準的な場所で探します：

- Windows：`C:\Program Files (x86)\Steam`、`C:\Steam`、`D:\Steam`、`E:\Steam`
- Linux：`~/.steam/steam`、`~/.local/share/Steam`、および Flatpak の場所
- （Windows ではレジストリに登録されたカスタムのインストール先も確認します）

主な原因：

- Steam がインストールされていない → store.steampowered.com からインストール
- Steam が標準以外の場所にインストールされている → Maida を起動する前に、環境変数 `MAIDA_WINDOWS_STEAM_ROOT` に Steam フォルダを設定

Steam は起動している必要はありません。Maida はディスクから直接ライブラリを読み取り、ゲームは Steam URL で起動します（必要であれば Steam が自動的に起動します）。

### ボタンが反応しない

ほとんどのボタン（やる、これじゃない、プレイ、解除、Maida に戻る、間合のカード）は短く押せば反応します。臨のアンカーと間合の「想いを留める」は3秒の長押しが必要です。手の震えやゲームパッドの誤操作で、うっかり起動しないための意図的な設計です。

反応しないときは、たいてい中途半端な押し方になっています。短押しには長すぎて、3秒の長押しには短すぎる状態です。もっと素早く押すか、3秒しっかり押し続けてください。

### Windows が「このアプリは安全ではない可能性があります」と表示する
これは SmartScreen 警告です。詳しい説明と対処方法は、上の **インストール前に** をご覧ください。

### ゲームが起動しない
Steam でそのゲームが普通に起動できるか確認してください。一部のゲームは、初回起動の前に手動での設定が必要です。

## 設計思想（興味があれば）

ほとんどのゲームランチャーは、閲覧を助けるために作られています。けれどライブラリを眺め続けるほど、決めるのは難しくなります。

Maida は閲覧を最小限にとどめます。最近開いたいくつか、残してあるいくつか、届いたばかりのいくつか。あるいは臨で、1つだけ。決めるのは、いつもあなたです。

> maida is the space you pass through before you begin.
